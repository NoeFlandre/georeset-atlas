# GeoReSeT Atlas

**Status: NOT RELEASE-READY.** The dataset is not release-ready yet. This page is a draft.

The Atlas uses three source datasets. Each source is pinned to one revision.

- `description`: the Description source.
- `website`: the Website source.
- `wiki`: the Wiki source. It includes Wikipedia and Wikivoyage data.
